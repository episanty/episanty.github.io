Chimera (Chiral Measures Research Assistant) is a Wolfram Mathematica package which contains code and tools useful to quantify the chirality of a distribution, and to apply those tools to photoelectron momentum spectra, such as might be obtained from strong-field ionization of chiral molecules, or of achiral systems driven by chiral fields.
